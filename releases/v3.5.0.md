# Group Password Reset 3.5.0

- Refresh the admin screen with the THRG mascot, Site Inspector styling, clearer account and confirmation sections, and result-count tiles.
- Add **Notify administrators**: select administrator recipients, add a note, preview the completed summary, and send a separate email to each recipient. Summary availability expires after 15 minutes.
- Identify emails with `[domain] [Group Password Reset]` subject tags. Administrator summaries now use readable WordPress-style paragraphs, site details, counts, follow-up guidance, and a dashboard link.
- Keep only the most recent 20 per-user result rows, removing older rows as processing continues. Summary counts cover the whole run.
- Display **Done! Password reset complete.** in bold and clarify mail acceptance versus delivery.

The reset engine retains explicit scope selection, exclusions, required confirmation, batches of 20, optional affected-user notifications, and the non-JavaScript fallback. Summary emails exclude passwords, reset links, and individual account details.

Validation: shared PHPCS, PHP/JavaScript syntax, notification regressions, updater-message regressions, result-row retention checks, ZIP integrity and bundled updater completeness. Zendogs browser checks covered desktop/mobile layout and simulated batched results. Real local SMTP capture through Mailpit verified administrator summary content and subject.

External inbox delivery, a full no-JavaScript submission, screen-reader testing, and the full declared WordPress/PHP compatibility matrix were not exercised. Local checks do not establish production security clearance. Consider the Codex Security diff-review reminder in the project documentation.
