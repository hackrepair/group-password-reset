Reset a whole group's passwords. Safely, in one go.

After a break-in, a staff change or a scare, you need a lot of passwords reset, and you need it done right. Group Password Reset works through everyone, one role or just the administrators, skips the accounts you exclude, and can email each person a secure reset link instead of a raw password.

Some days, one password isn't enough.

Resetting accounts one at a time is slow, and it is easy to miss someone. This does a whole group in one run and shows you exactly what happened.

  • After a security problem

    Once the site is clean, make every old password useless before anyone logs in again.

  • When staff change

    Reset the roles that a former employee or contractor could have used.

  • Handing a site over

    Start a new owner or client on fresh passwords, with a reset link in their inbox.

  • Routine hygiene

    Rotate passwords for one role on your own schedule, with a record that you did.

What it does

Open Tools › Group Password Reset. Pick who, say who to skip, confirm, and go.

  • Reset all users, a single role, or administrators except you
  • Skip the usernames you list, and remember them between runs
  • Email each person a secure reset link, never a raw password
  • Or run in reset-only mode and tell people another way
  • Works in batches of 20, with or without JavaScript
  • Shows the latest 20 results, with counts for the whole run
  • Email your administrators a branded summary afterward
  • Writes an audit log of when resets started and finished
  • Subjects carry the site and plugin, like [example.com] [Group Password Reset]
  • Updates arrive on the normal Plugins screen

Careful with other people’s accounts.

  • Reset links, not passwords
  • Administrators only
  • Audit log, no usernames
  • Updates from GitHub

The plugin resets passwords first and then tries to send the emails. A mail failure never undoes a reset, so use reset-only mode if you plan to tell people another way. Resetting invalidates current passwords, so the plugin asks you to confirm first.

The only outside requests are update checks against this project’s GitHub releases. It is not a security scanner or a login limiter. If you think your site has been hacked, The Hack Repair Guy can help.

Install it in a minute

  1. Download the zip from the button below.
  2. In WordPress, open Plugins › Add New › Upload Plugin, choose the zip and activate it.
  3. Open Tools › Group Password Reset and choose Accounts to reset. Add any usernames to exclude.
  4. Choose whether to email reset links, tick the confirmation, and select Reset Passwords.
