Notifications and confirmation

Passwords change before emails are attempted. If an email fails, the password reset still takes effect. You may need to help that user regain access.

In the plugin, this action resets passwords for the selected scope. This mockup only shows sample results.
How password resets work
  1. Select an account scope and list any usernames to exclude.
  2. Review the notification choice and acknowledge the password change.
  3. Passwords are reset in batches; email attempts follow unless disabled.
  4. Review the totals and the outcome for each user.
