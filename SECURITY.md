# Security Policy

## Reporting a Vulnerability

Please do not open public GitHub issues or discussions for security vulnerabilities.

Report privately through GitHub:
https://github.com/hackrepair/group-password-reset/security/advisories/new

Please include the affected version, reproduction steps, required privileges or preconditions, an impact summary, and a proposed fix or mitigation if you have one.

## Supported Versions

Security fixes are made against the latest release.

See [MAINTAINING.md](MAINTAINING.md) for the security model and review guardrails.
